# Machines that ship with Jarvis

Jarvis can take these apart as holograms out of the box ("拆解一台汽车发动机", "show me the Raptor engine").
Each machine is a figure page (`.html`, parts and teardown order) plus its 3D point cloud (`.holo.json`).
Jarvis also looks in `~/.jarvis/holo/` and on the Desktop, so you can add your own the same way; a file there
with the same name wins over the one here.

| File | Machine | Source |
|---|---|---|
| `raptor-engine.*` | Raptor 2 rocket engine | figure from the [anatomy](https://github.com/wheresryan22/anatomy) examples (MIT, © 2026 Ryan); point cloud made for Jarvis |
| `car-engine.*` | inline-four turbo car engine | made for Jarvis |
| `gearbox.*` | six-speed manual gearbox | made for Jarvis |
| `electric-motor.*` | permanent-magnet motor | made for Jarvis |
| `centrifugal-pump.*` | centrifugal pump | made for Jarvis |
| `gas-turbine.*` | heavy-duty gas turbine | made for Jarvis |
| `aircraft-turbofan.*` | high-bypass turbofan | made for Jarvis |
