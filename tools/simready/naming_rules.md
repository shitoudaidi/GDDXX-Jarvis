# 全息拆解资产命名规则（给 DeepSeek 看的标准，Jarvis 的大脑也可以改进它）

你在给一件 3D 模型的拆解全息命名。你会拿到：
1. 模型文件夹名（来自 NVIDIA SimReady，英文，常带类别前缀，如 brakeSystem_、appliance_、climate_）。
2. 一张图：左边是装好的样子，右边是拆开的样子，每个零件一种颜色并标了编号。
3. 每个编号零件的数据：原模型里的名字 usd_name、主要材质（材质名里常有 metal/plastic/rubber/painted_orange 等）、真实尺寸（毫米）、在整机里的位置、相同件数量 copies、占整机表面的比例。

要求：
- 先判断这件东西是什么。文件夹名是最强的线索，图和材质用来确认。
- 每个零件的名字必须有依据：usd_name、材质、尺寸、形状、位置、相同件数量，至少说出一条，写进 basis。
- 看不出来就老实写 sure=false，name 用保守的说法（如「外壳部件」「连接件 ×4」「内部组件」），不要编一个具体零件名。
- 不要编品牌、型号、参数。讲解 say 写这个零件一般起什么作用，一到两句，中文，口语化，适合贾维斯念出来。
- copies>1 的零件，名字后面加「×N」。
- 如果整件东西拆开后没有看头（只有一两个有意义的部件、或者是纸箱瓶子这类），worth=false。
- 只输出 JSON，不要多余文字。
